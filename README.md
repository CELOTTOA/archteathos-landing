# Archteathos

Landing indipendente di Archteathos. Dominio: `https://archteathos.it/`. Contatto: `info@archteathos.it`. P. IVA IT01374730933, Pordenone (PN), Italia.

Sito statico senza build o dipendenze. GitHub Pages pubblica dal branch `main`, cartella radice. La pagina usa soltanto asset locali. Privacy, Cookie e Termini d’uso sono inclusi e collegati dal footer.

Aprire `index.html` nel browser oppure avviare `python -m http.server 8080 --bind 127.0.0.1`.

I soli file pubblici provengono dalla cartella `landing/` del progetto Archteathos. Non sono presenti codice dell’applicazione, rilievi originali, chiavi API o script di generazione. I fogli tecnici sono esempi dimostrativi, i render hanno una cornice convenzionale.

Il sito non dipende dal repository o dall’hosting di devsoftiq.cloud. I percorsi delle pagine e delle immagini sono relativi; gli URL canonici, la sitemap e Open Graph puntano ad archteathos.it.

Per il collegamento del dominio e il mantenimento della posta Aruba consultare `CONFIGURAZIONE-DNS.md`.
